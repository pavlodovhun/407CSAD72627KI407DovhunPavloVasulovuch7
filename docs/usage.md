# Використання проєкту

## Запуск агента Copilot

1. Відкрийте кореневу папку репозиторію у VS Code.
2. Відкрийте Copilot Chat.
3. Виберіть агента `build-engineer`.
4. Введіть `/init`, щоб виконати початкове налаштування проєкту.
5. Введіть `/check`, щоб перевірити структуру, збірку, тести та CI.

## Локальна збірка

Запускайте скрипт із кореня репозиторію:

- Linux/macOS:

  ```sh
  ./ci.sh
  ```

- Windows:

  ```bat
  ci.bat
  ```

Скрипт конфігурує та збирає проєкт, запускає CTest і копіює виконуваний файл до `dist/`.

## Запуск `hello`

- Linux/macOS:

  ```sh
  ./dist/hello
  ```

- Windows:

  ```bat
  dist\hello.exe
  ```

## Запуск тестів

Із кореня репозиторію виконайте:

```sh
ctest --test-dir build -C Release --output-on-failure
```
